# AI Agents and Agentic AI with Python & Generative AI

**Provider:** Coursera  
**Status:** In progress

## Purpose

This course is helping me understand multi-step LLM workflows and the basic structure behind AI agents. I am using guided Google Colab notebooks to explore how prompts, model responses, Python, and APIs work together.

## Topics Explored

- System and user message roles
- Sequential prompting and response reuse
- Multi-step LLM workflows
- Basic agent loops and tool-oriented thinking
- Calling a generative AI model through LiteLLM
- Storing API keys securely in Google Colab
- Extracting and reusing model-generated Python code
- Documenting and improving generated output

## Hands-On Learning

- Ran and reviewed three guided Python notebooks
- Adapted prompts and variables to test an even-or-odd Python function request
- Passed generated code into follow-up prompts for documentation and improvement
- Used LiteLLM with Gemini in Google Colab
- Practiced troubleshooting setup, variable, and model-service errors

## What I Learned

The most important lesson was that a multi-step AI workflow can be created by storing one model response and using it as input for the next step. I also developed a clearer understanding of system versus user instructions, using f-strings to insert generated content, and why model output needs validation and error handling before it is reused.
