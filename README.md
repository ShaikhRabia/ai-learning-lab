# AI Learning Lab

I enjoy taking messy processes, organizing information, and using technology to make work easier for people. This repository documents my journey as I build practical skills in AI and Python through hands-on learning and projects, while exploring how these tools can support process automation and improve real-world workflows.

## Current Focus

- Building foundational knowledge of generative AI and agentic workflows
- Practicing Python through guided notebooks and exercises
- Understanding prompts, model responses, APIs, and multi-step LLM workflows
- Exploring how AI and Python can support process automation

## Repository Structure

- **AI Assistant/** — Notes and comparisons related to AI assistants and tools
- **learning/** — Course notes, notebooks, exercises, and completion evidence organized by provider
- **projects/** — Hands-on projects and experiments
- **reference/** — Supporting references and reusable learning resources
- **assets/** — Images and other files used throughout the repository

## Learning Approach

This repository reflects an active learning process. Course-provided notebooks and starter code are identified separately from my own modifications, experiments, reflections, and troubleshooting notes. The goal is to document genuine progress without overstating my current level of experience.
